# PeerMail
## 概要
本ソフトウェアはP2Pにより直接相手とメッセージを送受信するメッセンジャーツールです。
Outlookがサーバーダウンしていても使えます。
ユーザーはホストとクライアントに役割が分かれており、同時に両方の機能を使うこともできます。
ホストはネームサーバーとして動作しIDから相手のIPアドレスを割り出しクライアントに情報提供します。
クライアントはホストから教えられたIPアドレスを元に相手とハンドシェイクして本人確認を行います。
本人確認は公開鍵暗号の署名により認証し、本人と確認できた場合にメッセージを送信します。
受信側がポート開放している場合はメッセージは即時送信されますが、ポート開放していない場合は受信側から送信側に自分宛のメッセージがあるか問い合わせを行うことで受信します。
ホストによる宛先検索を使う場合は、ホストのIPアドレスとポート番号をINIファイルに記載してから起動してください。
ホスト同士はP2Pで繋がるため複数ホストが連結している場合は自動的にピアリストに追加されていきます。
ホストがいない場合でもIDの他に相手のIPアドレスとポート番号が分かれば送信可能です。
本ソフトウェアを起動すると自動生成された鍵を元にIDが作られますので通信する相手にそのIDを連絡してください。
送信側の発言権を優先するため拒否機能はありません。
その代わりメッセージの振り分け機能を提供しています。
また匿名メッセンジャーではないため通信に特別な暗号化は行っていません。
自分の公開鍵と暗号鍵は暗号化することなくローカルにテキスト保存されますので盗まれないように注意してください。
